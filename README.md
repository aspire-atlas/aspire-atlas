# Aspire Atlas

**Agentic social marketing for brands, agencies and creators.**

## Install

1. In Cowork, open **Customize** in the sidebar, then **Plugins**.
2. Select **Add marketplace** and enter:

   ```text
   aspire-atlas/aspire-atlas
   ```

3. Select **Browse plugins**, find **Aspire Atlas**, and click **Install**.
4. Open **Connectors** in the sidebar, find **Aspire**, and click **Connect**.
   Sign in when prompted.
5. Start a new chat and run `/aspire`.
